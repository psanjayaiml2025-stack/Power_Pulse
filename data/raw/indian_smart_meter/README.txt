Place the IIT Bombay SEIL Indian smart-meter CSV files here.

Supported:
- 1.csv ... 39.csv with TS,V1,V2,V3,W1,W2,W3
- OR virtual_dataset.csv with Date,Time,Energy and optional V1,V2,V3

Do not rename or edit the numbered files.
Run from the project root:
    python data\download_indian_dataset.py
